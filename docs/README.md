# Muhammad Umair – Portfolio

Static portfolio site for GitHub Pages. No build step required.

## Deploy to https://mumairumer.github.io

1. On GitHub, create a **public** repository named exactly `mumairumer.github.io`.
2. Upload everything in this folder (`index.html`, `assets/`, `.nojekyll`, `README.md`) to the repository root.
3. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. After a minute or two the site is live at `https://mumairumer.github.io`.

## Editing

- Text and layout: `index.html`
- Photo: `assets/umair.jpg`
- Resume download: `assets/Muhammad-Umair-Resume.pdf` (replace the file, keep the name)
- Stats (16+ years, 50+ projects, etc.): search for `class="stats"` in `index.html`
